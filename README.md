# 🎨 Manim Mathematical Animations & Visualizations

Welcome to my repository dedicated to **mathematical animations**, **concept visualizations**, and **educational video assets** built with the [Manim](https://www.manim.community/) engine.

This space hosts Python scripts, custom animation scenes, and visual content created for my educational math pages.

---

## 📌 Project Goals

- Create high-quality mathematical animations for educational content.
- Visualizing complex concepts in algebra, calculus, geometry, and problem solving.
- Build reusable custom Manim components and scene templates.

## 🛠️ Tech Stack & Tools

- **Engine:** [Manim Community Edition](https://www.manim.community/) (Python 3.x)
- **Language:** Python
- **Rendering & Output:** LaTeX, FFmpeg, Cairo
