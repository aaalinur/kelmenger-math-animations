# 📐 Kelmenger Math Animations (Manim)

Welcome to the official code repository for [**@kelmenger.math**](https://www.instagram.com/kelmenger.math/)! 

Here you'll find the Python scripts used to generate visual mathematical concepts, geometric proofs, and algorithmic animations built with **Manim** (Mathematical Animation Engine).
