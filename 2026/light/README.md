# Light

This folder contains short-form visual studies involving light, motion, and stylized diagrams.

## Included files

- `m.py` — main animation logic
- `sss.py` — supporting scene or motion study
- `Fermat.jpg` — reference or image asset
- `asan.swim.png` and `asan.walk.png` — character asset variations
- `usen.swim.png` and `usen.walk.png` — additional character asset variations
- `rock-svgrepo-com.svg` — vector rock asset
- `ball.png` or related assets if present in the scene directory

## Render

From this directory, run:

```bash
manim m.py
```
