# 🟦 Sum of Consecutive Odd Numbers ($1 + 3 + 5 + \dots + (2n-1) = n^2$)

This Manim animation proves that the sum of the first $n$ consecutive odd integers is always equal to a perfect square ($n^2$), using both **Mathematical Induction** and a **Geometric Visual Proof**.

## 📌 Animation Flow

1. **Algebraic Induction Proof:** Demonstrating step-by-step mathematical logic for $n=1, k, k+1$.
2. **Geometric Square Construction:** Building nested L-shaped layers around a center block to visually form larger $n \times n$ squares.
