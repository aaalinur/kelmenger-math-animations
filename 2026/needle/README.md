# Needle / matchstick problem

This folder contains a geometric probability visualisation based on the classic needle problem.

## Main script

- `needle_matchstick.py` — main animation scene
- `first.py` — legacy file kept for compatibility
- `match.png` — visual asset used in the animation

## Render

From this directory, run:

```bash
manim needle_matchstick.py
```

## Notes

The older generic file name `first.py` was renamed to `needle_matchstick.py` to describe the animation content more clearly.
